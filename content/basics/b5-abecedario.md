# Lo básico · B5 — El abecedario (The alphabet)

**Can-do:** *Puedo deletrear mi nombre, entender cuando alguien deletrea y decir un correo electrónico.*
**Level:** Basics · **Free:** yes · **Offline:** yes · **Status:** DRAFT — self-reviewed

Privacy: when learners practice their **own** name, it stays on the phone only and is never sent or saved.

---

## Lesson 1 — Letras de la A a la M

**1. Situation**
> En HR, por teléfono o en un formulario te van a pedir deletrear. Las letras en inglés suenan muy diferente.

**2. Listen first**
> 🔊 *A, B, C, D, E…* — *Is that B or V?* — *G as in "go".*

**3. Key chunks**
| Letter | Sounds like | Careful! |
|---|---|---|
| A | éi | no es "a" |
| B | bii | |
| C | sii | |
| D | dii | |
| E | ii | ¡suena como la **I** en español! |
| F | ef | |
| G | yii | |
| H | éich | |
| I | ái | ¡no es "i"! |
| J | yéi | |
| K | kéi | |
| L | el | |
| M | em | |

**4. Tip**
> Las más difíciles: **E = ii**, **I = ái**, **A = éi**. Practícalas hasta decirlas sin pensar.
> *G* (**yii**) y *J* (**yéi**) también se confunden. Si no estás seguro, di una palabra: *"G as in go"*.

**5. Practice**
1. 🔊 *ii* → **E** ✔ · I · A
2. 🔊 *ái* → **I** ✔ · E · Y
3. 🔊 *éi* → **A** ✔ · E · I
4. 🔊 *yéi* → **J** ✔ · G · H

**6. Shadow:** A–M in order, then *A, E, I* back and forth.

## Lesson 2 — Letras de la N a la Z

**1. Situation**
> Ahora el resto del abecedario.

**2. Listen first**
> 🔊 *N, O, P, Q…* — *W is "double U".* — *Z, like a bee: zzz.*

**3. Key chunks**
| Letter | Sounds like | Careful! |
|---|---|---|
| N | en | |
| O | óu | |
| P | pii | |
| Q | kiú | |
| R | ar | |
| S | es | |
| T | tii | |
| U | iú | |
| V | vii | dientes de arriba sobre el labio de abajo |
| W | dábel-iu | significa "doble U" |
| X | eks | |
| Y | uái | |
| Z | zii | zumbido, como una abeja: *zzz* |

**4. Tip**
> *B* (**bii**) y *V* (**vii**) suenan diferente en inglés. Si te preguntan *"B or V?"*, contesta con una palabra: *"V as in Victor."*
> En EE. UU. la Z se dice **zii** (no "zed").

**5. Practice**
1. 🔊 *uái* → **Y** ✔ · W · I
2. 🔊 *dábel-iu* → **W** ✔ · U · V
3. 🔊 *ar* → **R** ✔ · A · Ñ
4. 🔊 *kiú* → **Q** ✔ · K · U

**6. Shadow:** N–Z in order, then *B / V*.

## Lesson 3 — Deletrea tu nombre y tu correo

**1. Situation**
> En HR te piden tu apellido y tu correo electrónico.

**2. Listen first**
| | English | Español |
|---|---|---|
| Ms. Brown | What's your last name? | ¿Cuál es tu apellido? |
| María | López. | López. |
| Ms. Brown | How do you spell that? | ¿Cómo se escribe? |
| María | L - O - P - E - Z. | L - O - P - E - Z. |
| Ms. Brown | Is that E or I? | ¿Es E o I? |
| María | E. | E. |
| Ms. Brown | And your email? | ¿Y tu correo? |
| María | maria dot lopez at example dot com. | maria punto lopez arroba example punto com. |

Question: *¿Qué letra no entendió Ms. Brown?* → **La E** ✔ · La L · La Z

**3. Key chunks**
| English | Sounds like | Español |
|---|---|---|
| How do you spell that? | jáu du iu spel dat? | ¿Cómo se escribe? |
| L - O - P - E - Z | el - óu - pii - ii - zii | (deletreo) |
| at (@) | at | arroba |
| dot (.) | dat | punto |
| My email is… | mai ímeil is… | Mi correo es… |

**4. Tip**
> Para el correo: **@ = "at"**, **. = "dot"**. Ejemplo: *maria.lopez@example.com* = *"maria dot lopez at example dot com"*.
> Practica tu nombre y apellido hasta deletrearlos sin pensar. En HR te lo van a pedir muchas veces.

**5. Practice**
1. 🔊 *G - O - M - E - Z* → write **GOMEZ**
2. 🔊 *R - I - V - E - R - A* → write **RIVERA**
3. 🔊 *jose dot cruz at example dot com* → **jose.cruz@example.com** ✔ · josedotcruz@example.com
4. **Your name:** type your first and last name → the app plays each letter, you repeat. *(Stays on the phone only.)*

**6. Shadow:** the trouble letters, then the learner's own name.

**7. Mini task**
> 🔊 *"How do you spell your last name?"*
→ The learner spells their own last name out loud (speech check per letter).

## Unit game — *Dictado de letras* (Spelling dictation)

No AI, works offline.
- 8 common Latino last names and 4 work words are spelled at normal speed (*"H - E - R - N - A - N - D - E - Z"*, *"P - A - L - L - E - T"*).
- The learner types what they hear. Mistakes on E/I/A, G/J, B/V go into the daily review.
